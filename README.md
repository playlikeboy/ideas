## 🧩 Standard idea record

Every idea should eventually contain:

1. **One-line pitch**
2. **Problem**
3. **Target users**
4. **Solution**
5. **Why now**
6. **Core workflow**
7. **Business model**
8. **Distribution**
9. **Competitive landscape**
10. **Risks and assumptions**
11. **Validation plan**
12. **Status / priority**
13. **Relevant links**
14. **Contacts / owner**
15. **Next actions**

See [templates/startup.md](./templates/startup.md) for the full format.

## 🔒 Contact-data rule

Only publish contact information that is intentionally public or explicitly approved for publication. Personal phone numbers, private emails, credentials, API keys, and other sensitive information should never be added to this public repository.
