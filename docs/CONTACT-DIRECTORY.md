## What belongs in a contact record?

- Owner / maintainer
- Public profile links
- Product or demo link
- Public project repository
- Public company/social links
- Investor/application link when intentionally public
- Preferred contact channel

## What does not belong here?

Never commit:
- passwords
- API keys
- private tokens
- private phone numbers
- private email addresses
- personal addresses
- credentials or authentication links

If an idea has no public contact yet, mark it **TBD** rather than inventing one.
