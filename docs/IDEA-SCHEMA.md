# Idea Schema

Every Markdown idea should use YAML frontmatter followed by human-readable sections.

## Required frontmatter

```yaml
---
title: Idea Name
description: One-sentence description
status: backlog
type: startup
tags:
  - ai
  - saas
created_at: 2026-09-25
updated_at: 2026-09-25
priority: 3
link: null
---
```

## Recommended sections

### 1. Snapshot
The idea in one screen.

### 2. Problem
What is broken, expensive, slow, confusing, or underserved?

### 3. Target users
Who experiences the problem and who pays?

### 4. Solution
What exactly is being built?

### 5. User workflow
Describe the experience from first touch to recurring value.

### 6. Business model
Revenue model, pricing hypotheses, and possible expansion.

### 7. Distribution
How the first 10, 100, and 1,000 users could be acquired.

### 8. Competition
Direct alternatives, indirect alternatives, and why users might switch.

### 9. Moat
Data, network effects, workflow lock-in, distribution, brand, or technical advantage.

### 10. Risks
List the assumptions that could kill the idea.

### 11. Validation
Experiments that can prove or disprove the biggest assumptions.

### 12. Roadmap
Now / Next / Later.

### 13. Metrics
The small set of numbers that matter.

### 14. Links
Website, demo, repository, designs, research.

### 15. Contacts
Link to the corresponding record under `contacts/`.
